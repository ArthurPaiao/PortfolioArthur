## 🏗️ Como foi construído (Arquitetura Técnica)

Este portfólio foi desenvolvido com foco em performance e simplicidade, seguindo uma abordagem de *Single Page Application* (SPA) leve, sem a necessidade de *frameworks* pesados ou instalação de dependências locais (Node.js/NPM).

* **Estrutura Base (HTML5):** Código semântico dividido em seções claras (Início, Sobre, Competências, Experiência e Contato), utilizando rolagem suave (`scroll-smooth`) nativa.
* **Estilização (Tailwind CSS):** Implementado via CDN para uma prototipagem rápida e responsiva. O *script* de configuração do Tailwind foi customizado no próprio arquivo para estender o tema padrão, adicionando:
  * Paleta de cores personalizada (tons de roxo e *slate* profundo para o modo escuro).
  * Animações customizadas (`fade-in-up`) para a entrada dos elementos na tela.
* **Ícones (Lucide):** Utilização da biblioteca *Lucide Icons* via CDN para uma iconografia consistente e moderna.
* **Interatividade (JavaScript Vanilla):** *Scripts* puros e eficientes responsáveis por:
  * **Dark Mode:** Alternância nativa de temas (claro/escuro) com persistência de dados no `localStorage` do navegador, mantendo a preferência do usuário nos próximos acessos.
  * **Micro-interações:** Função nativa de *Copy to Clipboard* (copiar para a área de transferência) no endereço de e-mail, oferecendo *feedback* visual em tempo real.
* **Backend Serverless:** O formulário de contato foi integrado com a API do **Formspree**, permitindo o roteamento seguro das mensagens diretamente para o e-mail, dispensando a criação de um servidor backend próprio.
